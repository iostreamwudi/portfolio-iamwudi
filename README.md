# Portfolio · iamwudi

This repository contains the current static export of the portfolio website hosted at `portfolio.iamwudi.ltd`.

## Included

- Homepage and project detail pages
- ServicePilot and FORGE case-study assets
- InteractivePortrait layers and styles
- Portfolio folder interaction scripts and styles
- Static images, logos, and generated Next.js assets

## Run locally

Serve the repository root with any static HTTP server, for example:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080/`.

This is a deployable static snapshot, not the original private Next.js source tree.

## Editable source

The available editable source for the custom Hero portrait is in `source/interactive-portrait/`:

- `src/interactive-portrait.jsx`
- `interactive-portrait.css`
- `package.json` and `package-lock.json`
- the original portrait and layer assets

The website root contains the complete current static export used for deployment.
